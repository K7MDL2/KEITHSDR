The K7MDL Teensy SDR project files and info are in the subfolder SDR_RA8875.  

It supports both RA8875 4.3" and RA8876 7" touchscreen versions.

https://github.com/K7MDL2/KEITHSDR/tree/main/SDR_RA8875

Extensive documentation can be found in the Wiki pages at https://github.com/K7MDL2/KEITHSDR/wiki
